## Core Engineering Practices

* **Clean Architecture in Test Suites:** Page Object Model (POM), Screen Object Model, custom Cypress commands (`cy.session`, `cy.selectFile`, `cy.env`), Playwright fixtures/service objects, and keyword libraries with strict static linting (`ESLint`, `Robocop`).
* **Full Lifecycle QA Traceability:** Every project connects business acceptance criteria in **Gherkin BDD** (`specs/features/`) to structured **Test Plans**, **Test Cases**, **Bug Reports**, and automated assertions.
* **Data Hygiene & Isolation:** Self-contained test seeding and cleanup using PostgreSQL CTEs, MongoDB isolated containers, H2 in-memory seeds, and collision-free generators (`Faker`, `ULID`) — never relying on hardcoded production state or committed secrets.
* **API & Non-Functional Validation:** OpenAPI 3.0 contracts, Postman collections, HTTP `cy.intercept` / `APIRequestContext` contract assertions, and Artillery load/spike benchmarking (`p95`, `p99`, saturation error rate).
